会话与运行控制

把用户输入交给 Agent；管理资源、运行中的追加消息，以及 core run 结束后的重试和收尾。

输入
用户问题、配置、steer / follow-up
输出
启动或继续一次 core run，最终发出 agent_settled

agent_settled 表示会话活动收尾，结果是否正确还要验收。

Agent Loop

安排模型请求与工具执行，把结果加入上下文；根据工具、消息队列和 hook 决定下一轮或结束。

输入
当前消息、可执行工具、调度配置、取消信号
输出
assistant / toolResult、运行事件、agent_end

循环停下不等于业务成功；普通 loop 没有通用内置 maxSteps。

模型接入与响应流

把统一消息转换为模型协议，接收流式片段，产出文本、思考或工具调用组成的完整 assistant 响应。

输入
模型配置、规范化 transcript、请求选项
输出
start / delta / done / error，以及最终 AssistantMessage

模型提出 toolCall；真实工具由宿主执行。截断参数不能直接执行。

历史与上下文

用 entry 树保存历史，通过分支、context_edit 和最新压缩生成当前 projection，再组织下一次模型输入。

输入
消息、当前 leaf、上下文编辑、压缩预算
输出
持久历史、当前分支和模型可见的消息投影

原文在磁盘上不表示模型本次看得到；摘要有损，恢复历史不回滚文件。

工具执行与真实动作

找到实际工具，准备和校验参数，执行前检查，调用 execute，再处理结果并生成可关联的 ToolResult。

输入
完整 toolCall、schema、宿主权限与执行后端
输出
文件或服务效果、content / details、isError

工具成功不保证需求满足；错误或取消也不保证动作没有发生。

能力与方法扩展

Extension 接入代码与 hook；Skill 提供工作步骤；MCP 发现并调用外部工具，再适配回统一工具接口。

输入
扩展模块、SKILL.md、MCP server 能力
输出
可调用工具、行为规则、外部调用结果

注册、模型可见、可调用和授权是不同状态；Skill 文本不自动授予权限。

验证、安全与服务交付

用确定性实验检查机制，用真实效果和固定任务集评估结果；明确资源权限、隔离、任务状态和服务接口。

输入
预期、事件轨迹、文件或执行端结果、任务集
输出
通过 / 失败 / 未运行证据、Bad Case、服务验收结论

这是贯穿各模块的检查工作，不是 loop 默认附带的自动成功判定器。

子任务与持久恢复

普通示例启动独立 PI 子进程；durable 以 task、checkpoint 和 requestId 管理前台或后台子会话及恢复。

输入
独立任务说明、所有权、已保存阶段和提交 ID
输出
子任务答案、后台报告或恢复后的任务状态

可选扩展与实验路径；独立上下文不自动隔离文件，checkpoint 不自动保证外部动作只执行一次。
